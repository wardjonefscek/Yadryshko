## Соглашения

- orient2d > 0 — обход a → b → c против часовой стрелки.
- orient3d — знак det(a − d, b − d, c − d): > 0, если d ниже плоскости abc,
  а abc при взгляде сверху идут против часовой стрелки.
- Треугольники сетки снаружи обходятся против часовой стрелки; объём
  замкнутого тела больше нуля.
- `x.then(&y)` — сначала x, потом y.
- В SVG ось Y смотрит вверх, как в CAD.
- Пиксель сетки полуоткрытый: [g − ½, g + ½) по обеим осям.
- В корректной области внешние контуры идут против часовой, отверстия — по
  часовой; внутри обмотка 1, снаружи 0.
- `twice_area` — удвоенная площадь в квадратных шагах сетки, точно (i128).
- bulge > 0 — дуга против часовой стрелки; у контура против часовой она
  выпирает наружу. Path и Arc — в мм, Region и Ring — на сетке.
- offset: d > 0 — наружу, d < 0 — внутрь; d в мм.

## Хрупкие места (`РИСК:`)

- tol.rs, `GRID_LIMIT` — на нём держится точность 2D-предикатов в i128.
- grid.rs, `mm_to_grid` — десятичная середина шага может округлиться вниз.
- predicates.rs, `RANGE_2D` и `RANGE_3D` — где фильтру Шевчука можно верить.
- predicates.rs, `orient2d_grid_value` — без переполнения только в пределах сетки.
- seg.rs, `intersection` — числители до 2^125: запас i128 небольшой.
- boolean.rs, `MAX_ROUNDS` — если раундов округления не хватило, операция паникует.
- boolean.rs, `left_winding` — символический сдвиг; вызывается раз на компоненту.
- offset.rs, `sector` — крайние точки сектора обязаны считаться той же функцией,
  что и углы полос, иначе между кусочками появятся щели в доли микрона.
