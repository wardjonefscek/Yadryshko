## Решения

| Что | Решение | Почему |
| --- | --- | --- |
| Язык | только Rust; Python в проекте не используется | решение 30.10.2026 |
| Сторонние CAD-ядра | не используем, OpenCASCADE исключён | своё ядро |
| Внешние библиотеки | нет ни в ядре, ни в тестах | сборка без интернета; в среде Claude crates.io закрыт |
| unsafe-код | запрещён во всём проекте | ошибки памяти исключены на уровне компилятора |
| Единицы | мм; 2D — целые микрометры (i64), предел ±2^40 мкм | 2D-предикаты точны в i128 |
| 3D | f64; предикаты — фильтр Шевчука и своя длинная арифметика | точный знак без всяких допусков |
| Случайные тесты | свой testkit вместо proptest: SplitMix64, сид на каждый случай | без внешних библиотек |
| Эталон точной арифметики | целые i128 и сверка по модулю двух простых чисел | эталон не зависит от нашей длинной арифметики |
| Версия Rust | закреплена: 1.97.0 в rust-toolchain.toml | формат и clippy одинаковы у всех; обновлять осознанно |
| Стенд | `cargo xtask` на Rust, без зависимостей | одинаково на Windows и Linux; собирается, даже когда ядро сломано |
| Сиды | днём постоянный, ночью новый на каждый раунд | днём прогоны повторяются, ночью ищут новые случаи |
| 2D-булевы | snap rounding (Хобби) на сетке 1 мкм: точки пересечений округляются в «горячие пиксели», рёбра проходят через их центры | результат снова на сетке и без пересечений; сдвиг не больше 0,71 мкм |
| Правило заливки | ненулевая обмотка; любая операция — правило `(в A, в B) → в результате` | одна процедура на все операции и на нормализацию входа |
| Корректная область | контуры не пересекаются и не накладываются, касание в точке можно; слева от ребра обмотка 1, справа 0; внешние против часовой, отверстия по часовой | проверяет `Region::check`; результаты операций корректны всегда |
| Обмотка у ребра | луч вправо из середины ребра, сдвинутой на символический ε влево | без особых случаев «луч через вершину» |
| Самопересекающийся контур | допустим во входе (`Ring`); нулевая ориентированная площадь — не ошибка | «бантик» по ненулевой обмотке закрашен |

## Правила работы

1. Сначала ЖУРНАЛ.md и КАРТА.md, потом только нужные модули.
2. После каждой правки — `cargo xtask check` (секунды). Перед выпуском
   версии — `cargo xtask check --full`. Ночью — `cargo xtask night 7`,
   утром — отчёт из `reports/`.
3. Найденная ошибка сначала становится тестом, потом чинится.
4. Хрупкие места помечены `РИСК:`: менять их только вместе с тестами.
5. Упавший случай печатает команду повтора:
   `YADRO_SEED=… YADRO_CASES=1 cargo test -p yadro-core <тест>`.
6. Код и объёмную работу Claude начинает только после отдельного «да».
7. Для Claude: в его среде нет интернета для rustup. Если там установлен
   только stable той же версии, сделать её доступной под закреплённым
   именем: `ln -s stable-x86_64-unknown-linux-gnu
   ~/.rustup/toolchains/1.97.0-x86_64-unknown-linux-gnu` (из папки
   ~/.rustup/toolchains). Если версия другая — `RUSTUP_TOOLCHAIN=stable`
   и предупредить, что замечания clippy могут отличаться.

## Отложено на следующие ступени

- Ужатие упавшего примера — ступень 1, шаг 5.
- Полная карточка ошибки — ступень 1, шаг 5 (пока тест булевых операций
  кладёт SVG с A, B и результатом в папку временных файлов тестов);
  просмотр 3D — в браузере со ступени 2.
- Обмотка у ребра считается за O(n) на ребро, операция — O(n²). Для
  контуров TopOpt из тысяч рёбер — заметающая прямая (шаг 4).
- cargo-fuzz, cargo-mutants, cargo-llvm-cov ставятся как инструменты на ПК
  или сервер; в сам проект они не входят.

## История

- **0.1.3** — 05.11.2026 — ступень 1, шаги 1–2. Отрезки (`seg`): точная
  классификация пересечений, точка пересечения дробью, попадание в
  полуоткрытый пиксель. Контур (`Ring`): упрощение, точная площадь,
  обмотка, положение точки, простота. Область (`Region`): инвариант и его
  проверка, нормализация любых контуров по ненулевой обмотке. Булевы
  операции (`boolean`): объединение, пересечение, разность, xor и
  произвольное правило; snap rounding с повторными раундами, сборка
  контуров по минимальному повороту. Каталог из 17 вырожденных случаев:
  совпадение, общая сторона, общая вершина, Т-стык, наложение сторон,
  вложение, касание отверстием, «плюс», почти параллельные рёбра, щепка,
  координаты у предела сетки, «бантик», пентаграмма, пустые операнды,
  встречные копии, сдвиг на шаг. Случайные пары: каждый результат
  проходит `check`, тождества площадей выполняются точно, точки вдали от
  границ классифицируются так же, как по исходным фигурам; полный прогон
  — 100 000 пар за 18 с. Тестов: 82 в ядре и 3 в стенде.
- **0.1.2** — 30.10.2026 — стенд переписан на Rust: `cargo xtask check`
  (быстрый и полный прогон) вместо bash-скрипта; версия Rust закреплена
  (1.97.0). Ночной режим `cargo xtask night`: новый сид на каждый раунд,
  отчёт с падениями по тестам и командой повтора. Проверено подложенным
