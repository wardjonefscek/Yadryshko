# yadro — своё CAD-ядро

Ядро для проектировщика самолётов и TopOpt: 2D-контуры, детали наборного
каркаса, точные операции, файлы на печать. Пишется по ступеням, и каждая
заканчивается воротами — набором тестов, которые должны быть зелёными.

Пройдена **ступень 0 «Фундамент»**. Идёт **ступень 1 «2D-ядро»**: готовы
контуры с отверстиями, булевы операции (объединение, пересечение, разность,
xor) — точные, на сетке 1 мкм, — дуги и эквидистанта (offset, скругления,
проверка под фрезу), профили крыла из файлов .dat и NACA, контур детали из
поля плотности топооптимизации. Подробности — в ЖУРНАЛ.md.

## Как запустить

Нужен только Rust (https://rustup.rs). Версия закреплена в
`rust-toolchain.toml`, rustup скачает её сам при первой команде. Чужих
библиотек нет, поэтому дальше проект собирается без интернета. Команды
одинаковы на Windows, Linux и macOS:

```
cargo xtask check           # быстрый прогон — после каждой правки
cargo xtask check --full    # полный прогон — перед выпуском версии
cargo xtask night 7         # ночной поиск ошибок на 7 часов
cargo run -p yadro-core --example rib   # пример: нервюра и траектория фрезы → target/rib.svg
cargo run -p yadro-core --release --example topopt_rib   # нервюра Clark Y по полю плотности
```

Ночной прогон берёт новый сид на каждый раунд и пишет отчёт в
`reports/night-ГГГГ-ММ-ДД-ЧЧММ.md`: какие тесты упали и готовая команда,
которая повторяет найденный случай. На сервере его удобно запускать по
расписанию, например через cron: `cd ~/yadro && cargo xtask night 7`.
